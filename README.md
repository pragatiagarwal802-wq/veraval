# Veraval Marine Nodes — Real-Time Data (README)

## What this is
Real-time marine + weather data for 140 coastal nodes near Veraval / Gir Somnath,
Gujarat. Fetched live from Open-Meteo Marine API + Weather API (free, public,
no key required).

**This is a SNAPSHOT, not a time series.** Every row reflects conditions at the
`observation_time` in that row — a single point in time, not historical data.
If you need data across multiple times/days for model training, we need to run
the fetch script repeatedly (manually or on a schedule) and combine snapshots —
this file alone is not enough for that.

## File
`veraval_nodes_REAL_data_<timestamp>.csv` — 140 rows, one per node.

## IMPORTANT — safe_to_venture is NOT a validated safety standard

`safe_to_venture` and `hazard_type` are generated by a simple placeholder rule:
- unsafe if wave_height_m > 2.5 OR wind_speed_kmph > 45
- these thresholds were picked as reasonable starting values, NOT sourced from
  an official INCOIS/IMD advisory standard

**Do not treat this column as ground truth for model training.** If you're
building a predictive/classification model, either:
1. Replace this rule with real INCOIS/IMD threshold values once we source them, or
2. Treat it as a baseline rule to compare your model against, not as labels

## Data source
- Marine variables: Open-Meteo Marine API (https://marine-api.open-meteo.com)
- Weather variables: Open-Meteo Weather API (https://api.open-meteo.com)
- Both free, public, no API key, no rate-limit issues at this scale

## Known gaps (not in this file — separate sourcing needed)
- Chlorophyll concentration (needed for PFZ estimation) — Copernicus Marine Service
- Tides — not yet sourced (Stormglass/WorldTides API is the likely path)
- PFZ advisories, cyclone/lightning alerts — INCOIS/IMD, no clean API (PDF/bulletin only)
